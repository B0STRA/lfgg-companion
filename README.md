# LFGG Companion

A small Windows tray app for [LFGG](https://lfgg.info). It notices which game you're playing (Steam, Epic, GOG), keeps **Playing now** on your LFGG profile current for the people you choose, and tells you when someone is looking for a group for that game.

**[Download for Windows](https://github.com/B0STRA/lfgg-companion/releases/latest/download/LFGG.Companion-win-Setup.exe)** · [More about it](https://lfgg.info/companion)

- Windows 10 (1809) or 11, 64-bit. Installs for your account only, no admin needed.
- Updates itself from this repository's releases.
- Privacy: it reads the installed-game lists Steam, Epic and GOG keep and the file paths of running programs, and sends LFGG only which game started and stopped. Details at [lfgg.info/companion](https://lfgg.info/companion).

This repository holds the releases. Questions or problems: support@lfgg.info.
